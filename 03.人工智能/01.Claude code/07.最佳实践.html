使用原则

1. 明确目标

# ❌ 模糊
> 帮我看看这个

# ✅ 明确
> 审查 src/auth/login.ts 中的用户认证逻辑
> 找出可能导致登录失败的原因

2. 提供上下文

# ❌ 缺乏上下文
> 优化这段代码

# ✅ 有上下文
> 优化 src/utils/calculate.js 中的排序算法，
> 这是数据处理模块，需要处理大量数据

3. 分步执行

# ❌ 一次性要求太多
> 创建一个完整的用户系统，包括注册、登录、权限、数据库

# ✅ 逐步实现
> 1. 先创建用户表结构
> 2. 然后实现注册接口
> 3. 接着实现登录接口
> 4. 最后添加权限控制

安全实践

敏感信息

不要让 Claude 处理：

  • API 密钥
  • 密码
  • 私钥
  • 个人隐私数据
# ❌ 危险
> 将这个 API_KEY=xxx 加入环境变量

# ✅ 安全
> 在 .env.example 中添加 API_KEY 占位符

权限确认

注意 Claude 的权限确认提示：

  • 文件修改
  • 命令执行
  • 网络请求
